# MyDiet
Applicazione che tiene traccia degli alimenti mangiati durante la giornata e calcola le relative calorie.

PWA costruita con Vite, TypeScript e Preact; i dati restano sul dispositivo (IndexedDB).

```bash
npm install
npm run dev     # sviluppo
npm test        # test
npm run build   # build di produzione
```

Il deploy su GitHub Pages avviene automaticamente a ogni push su `main`
(abilitare in *Settings → Pages → Source: GitHub Actions*).
